## DrawE / draw-empty v0.1.0

首个归档版本（与 `package.json` 的 `version` 一致）。

### 组件（Vue 3）

- **DrawEmpty**：插画空状态（插图、标题、描述、默认插槽、`#extra`、`#image`）。
- **UndrawImg**：按需加载 `undraw-illustrations/*.svg`，可单独使用。
- **accentColor**：支持 HEX；可通过 **createDrawEmptyPlugin({ accentColor })** 全局注入。

### 插件与导出

- **createDrawEmptyPlugin**：全局注册组件；可选全局主色。
- **drawEmptyDefaultAccentKey**：provide / inject 键（进阶）。
- 入口：**src/index.ts**（源码分发，业务侧需能编译 `.vue`）。

### 工具与文档

- **prepare:undraw** / **prepare:undraw:all**：拉取 unDraw SVG。
- **npm run pack**：生成安装包（默认输出到 **releases/**）。
- **VitePress** 文档站：指南、npm 接入、组件 API + Demo、插图浏览；**/readme-showcase** 与 README 实拍脚本。

### 依赖

- **peerDependencies**：`vue ^3.4.0`。

### 破坏性变更

无。
